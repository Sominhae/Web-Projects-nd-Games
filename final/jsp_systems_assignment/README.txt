JSP WEB TECHNOLOGY ASSIGNMENT
==============================

This ZIP contains four separate Oracle JSP + JDBC practice systems:

1. Online Library System
2. Doctor Appointment System
3. Cafeteria Order System
4. Student Club Event System

Each folder contains:
- README.txt
- schema.sql
- JSP form page
- JSP processing page
- style.css

GENERAL SETUP
-------------
1. Install Oracle Database and Apache Tomcat.
2. Run each project's schema.sql in Oracle SQL Developer or SQL*Plus.
3. Add the Oracle JDBC driver (ojdbc8/ojdbc11) to Tomcat or the project.
4. Replace 'your_password' in each processing JSP file.
5. Deploy a project folder in Tomcat's webapps directory.
6. Open the relevant JSP page in the browser.

NOTE
----
These are educational examples. For production projects, use Servlets,
DAO classes, connection pooling, server-side validation, and proper
exception handling instead of JSP scriptlets.
