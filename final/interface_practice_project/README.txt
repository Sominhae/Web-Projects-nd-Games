# Interface Practice Project

## Files
- index.jsp: Five HTML form interfaces
- style.css: Common styling
- script.js: Client-side validation and calculations
- process.jsp: Basic server-side validation and JSP processing

## Run
1. Install Apache Tomcat.
2. Copy this folder into Tomcat's webapps directory.
3. Start Tomcat.
4. Open:
   http://localhost:8080/interface_practice_project/index.jsp

## Important
This is a classroom practice project. For a real application:
- Use Servlets instead of large JSP scriptlets.
- Use JDBC/DAO classes for database operations.
- Use PreparedStatement for SQL queries.
- Perform both client-side and server-side validation.
